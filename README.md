# Emergency Waitlist Matching System — QueueMatch Local

A privacy-conscious, local-first operational coordination dashboard that screens verified waitlist records against cancelled appointment slots using transparent rules for urgency, travel feasibility, readiness, specialty/service fit, and verification status.

## Core capabilities
- 0–100 explainable matching suitability score
- Preferred / Suitable / Backup / Review / No Match
- Cancelled-slot intake and filtering
- Verified-waitlist validation
- Urgency-aware matching
- Travel-time feasibility scoring
- Readiness/completion scoring
- Service/specialty compatibility
- Slot fit and appointment-window compatibility
- Queue priority analytics
- Candidate comparison matrix
- Scenario lab for travel/readiness thresholds
- Export of scored matches to CSV
- 100% local processing; no external APIs

## Safety boundary
This is an operational matching aid. It does not diagnose patients, determine clinical eligibility, replace clinician triage, or guarantee that a suggested candidate can safely take a cancelled slot. Use only authorized, minimum-necessary, preferably de-identified records. Final scheduling and clinical decisions remain with qualified staff and applicable procedures.
